# 🔢 Number Sign Classifier (Positive / Negative / Zero Checker)

A lightweight C command-line program that takes a floating-point number from the user and classifies it as positive, negative, or zero.

This project demonstrates the implementation of multi-branch conditional statements (`else if`) and basic standard input/output operations in C.

---

## 🚀 Features
* **User Input:** Takes numerical inputs (including decimals) using `scanf` and double-precision variables (`double`).
* **Multi-Branch Logic:** Uses `if`, `else if`, and `else` control flow to evaluate three distinct numeric states.
* **Format Handling:** Correctly handles positive numbers ($a > 0$), exact zeros ($a = 0$), and negative values ($a < 0$).

---

## 💻 Tech Stack
* **Language:** C (C99 standard)
* **Compiler:** Apple Clang / GCC
* **Environment:** macOS, VS Code, Terminal
